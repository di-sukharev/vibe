# Tasks

Each file in this folder describes one product task.

## Create a task

- Name the file `NNNN-task_name.md`. `NNNN` is the next free four-digit number, for example `0007-user_login.md`.
- Write in simple words that a manager can understand.
- Describe what the user needs and why. Describe how to check the result.
- Do not write implementation details. The person who does the task decides them during the work.

## Complete a task

- When the work is complete, rename the file to `NNNN-task_name.done.md`, for example `0007-user_login.done.md`.
- Do not delete completed tasks. Do not reuse their numbers.
